# 🎮 Neue Bot Commands - Suka Supreme Bot v1.0

## 🎵 Music & Entertainment Commands

### /play <songname>
Spiele einen Song ab! Mit direkten YouTube-Links für beliebte Songs.
- Verfügbare Songs: bohemian rhapsody, shape of you, blinding lights, levitating, as it was, painkiller, starboy, uptown funk
- **Beispiel**: `/play bohemian rhapsody`

### /music <genre/song>
Musikempfehlungen und Genre-Informationen
- Verfügbare Genres: rap, pop, rock, edm, hiphop, metal, klassik
- **Beispiel**: `/music rap`

## 😂 Fun & Social Commands

### /roast @user
Verspotte einen User mit zufälligen lustigen Sprüchen
- **Beispiel**: `/roast @max`

### /compliment @user
Mache jemandem ein Kompliment
- **Beispiel**: `/compliment @sarah`

### /love @user
Schreib wer du liebst
- **Beispiel**: `/love @anna`

### /avatar
Zeige dein Profil-Avatar und Online-Status
- Automatischer Avatar basierend auf User-Nummer
- **Beispiel**: `/avatar`

## 📊 Profile & Level Commands

### /rank
Zeige deinen aktuellen Rang und Level
- Ränge: Anfänger → Novize → Junior → Senior → Meister → Legend → Titan → Gott
- **Beispiel**: `/rank`

### /profile [@user]
Detailliertes Profil anzeigen mit allen Infos
- Zeigt: Geld, Bank, Level, XP, HP, Rang, Items, Häuser, Autos, Jobs, Clans
- **Beispiel**: `/profile @max` oder `/profile` (dein eigenes Profil)

### /prestige
Upgrade dein Level - braucht Level 50!
- Setzt dein Level zurück auf 1
- Erhältst 5000€ Bonus
- **Beispiel**: `/prestige`

## 🔑 Owner-Only Commands (Neu!)

### /ban @user
Banne einen User vom Bot
- **Beispiel**: `/ban @spammer`

### /unban @user
Entbanne einen User
- **Beispiel**: `/unban @spammer`

### /resetuser @user
Setze einen User komplett zurück
- Löscht alle Items, Geld, Level
- **Beispiel**: `/resetuser @max`

### /broadcast <nachricht>
Sende eine Nachricht an alle User
- **Beispiel**: `/broadcast Die besten neuen Features sind live!`

### /addmoney <betrag> [@user]
Geld hinzufügen (nur Owner)
- **Beispiel**: `/addmoney 1000 @max`

### /stats
Bot Statistiken anzeigen (nur Owner)
- **Beispiel**: `/stats`

### /shutdown
Bot herunterfahren (nur Owner)
- **Beispiel**: `/shutdown`
